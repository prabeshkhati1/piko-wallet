# Piko Wallet notices

Piko Wallet is an independent web adaptation inspired by [Ivy Wallet](https://github.com/Ivy-Apps/ivy-wallet), an Android application by Ivy Apps Ltd and its contributors. The repository was reviewed as a design and behavior reference; Piko's Rust and browser implementation is new. Reused Raleway font files are accompanied by `static/fonts/OFL.txt`.
